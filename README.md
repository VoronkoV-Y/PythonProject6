# Проект - Курсовая работа по теме ООП

## Цель проекта
Реализовать программу, которая будет собирать данные о самолетах в воздушных пространствах тех стран, которые выбераем.

## Инструкции по установке и использованию разработанных классов, объектов, методов 
1. Скачайте проект
2. Установите окружение и зависимости согласно файлу pyproject.toml
3. Используйте классы, объекты, методы по необходимости

## Примеры работы с ними
* для создания экземпляра класса *APIConnectClass* вызовите *класс APIConnectClass*
* для создания экземпляра класса *InfoAeroplanesClass* вызовите *класс InfoAeroplanesClass*, внося в качестве параметров атрибуты самолета: ```"callsign", "country_rgstr", "baro_altitude", "velocity"```
* для сохранения данных в json-файл, получения и удаления данных используйте экзепляр класса *JSONSaverClass*, используйте функции ```add_info```, ```get_info```, ```delete_info```, внося в качестве параметров соответствующие параметры (*новые данные*, *позывной самолёта*)

## Дополнительно
Добавлен модуль `utils.py` в папке `src`.  Этот модуль содержит функции ```filter_aeroplanes```, ```get_aeroplanes_by_altitude```, ```sort_aeroplanes```, ```get_top_aeroplanes```, которые обрабатывают данные из API или JSON-файла, находящегося в папке `data` проекта. 
Функции используются для фильтрации, сортировки и последующего вывода данных и N необходимых самолетов по их высоте пользователю.
Также добавлен модуль `main.py` в основной директории проекта с функцией ```user_interaction``` для интерактивного взаимодействия с пользователем.
## Тестирование
Программный код был протестирован рядом тестов с использованием фикстур, patch, Mock.
Все тесты находятся в папке *tests* корневой директорией проекта.
