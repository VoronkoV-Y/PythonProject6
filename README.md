# Проект - учебный по теме E-commerce

## Цель проекта
Создать ядро для интернет-магазина с использованием ООП

## Инструкции по установке и использованию разработанных классов, объектов, методов 
1. Скачайте проект
2. Установите окружение и зависимости согласно файлу pyproject.toml
3. Используйте классы, объекты, методы по необходимости

## Примеры работы с ними
* для создания экземпляра класса *Product* вызовите *класс Product*, внося в качестве параметров атрибуты продукта: ```name, description, price, quantity```
* для создания экземпляра класса *Category* вызовите *класс Category*, внося в качестве параметров атрибуты продукта: ```name, description, poducts```
* для распаковки данных их json-файла и преобразования их в экзепляры класса *Category* используйте функцию ```data_load_from_json```, внося в качестве параметра название(путь) json-файла

## Дополнительно
Добавлен модуль `utils.py`.  Этот модуль содержит функцию ```data_load_from_json```, считывающую данные из JSON-файла, находящегося в папке `data` проекта. Функция считывает данные мз JSON-файла и подгружает данные 
по категориям и товарам, чтобы конвертировать их в объекты.
## Тестирование
Программный код был протестирован рядом тестов с использованием фикстур.
Все тесты находятся в папке *tests* корневой директорией проекта.
